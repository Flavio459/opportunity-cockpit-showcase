# Publication Boundary

This repository is a **portfolio showcase**, not the production system.

## Public

- problem statement;
- high-level architecture;
- synthetic user interface;
- synthetic opportunity data;
- evidence and verification concepts;
- human-gate behavior;
- selected implementation examples needed to prove the design.

## Private

- personal CV and application history;
- real recruiter/client/company records;
- real proposal content;
- private scoring weights and thresholds;
- internal economic strategy;
- provider credentials and endpoints;
- traces and benchmark datasets;
- operational memory;
- real outcomes;
- automation that performs external submissions;
- production infrastructure.

## Rule

Public GitHub should prove that the system can be designed and built without publishing the valuable or sensitive core.

All data in this repository is synthetic unless explicitly stated otherwise.
